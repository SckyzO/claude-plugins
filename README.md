# claude-plugins

Claude Code plugin marketplace for plugins maintained by SckyzO.

```text
/plugin marketplace add SckyzO/claude-plugins
```

| Plugin | Install | Repository |
|---|---|---|
| project-setup | `/plugin install project-setup@sckyzo-plugins` | [SckyzO/claude-project-setup](https://github.com/SckyzO/claude-project-setup) |
